## AI-with-Cyber-final-project


# Project Title: PromptShield 

Project Members: San Alexander, Neha Manickam, Ishaan, and Aakash 

Project Description: Please describe what you are planning to design and implement. I will give a sample below.  

We propose to develop an ML model that operates in the cloud to help users identify any personally identifiable information before they submit text or a query to a large language model. This model will analyze the user’s input and classify whether it has sensitive information such as email addresses, phone numbers, names, addresses etc.  Then the model will warn the user and disable the submit button until the input has been reviewed again by the user. We will train the model using labeled examples of inputs that contain PII and text that does not by using the PII Masking 200k Dataset. Then we will test our model by using new examples it has not seen before to determine its accuracy. We will use Python along with libraries such as pandas, scikit-learn and NumPy. We will also use Claude Code to help with debugging and documentation.
